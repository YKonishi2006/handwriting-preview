# 手書きプレビュー

便箋・メッセージカード・ハガキに手書きする前に、文章が用紙に収まるかを確かめるWebツールです。

**▶ 使ってみる: https://ykonishi2006.github.io/handwriting-preview/**

## できること

- 用紙の写真を読み込み、その上に文章を手書き風フォントで重ねて表示
- 書き出し位置・書ける範囲・文字の大きさをドラッグで調整
- 「約2行はみ出しています」「あと約3行書けます」のように、収まり具合を行数で表示
- 横書き／縦書き、行間・字間、書体、インクの色を変更
- 用紙の調整: 90°回転、傾き補正、拡大と位置合わせ、切り抜き（自由・ハガキ・便箋（A判）・正方形）、明るさ・コントラスト
- 仕上がりイメージをPNG画像で保存

画像はブラウザの中だけで処理され、どこにも送信されません。

## 使い方

1. 「用紙を選ぶ」から、用紙を真上から撮った写真を読み込む（「サンプル便箋で試す」でもOK）
2. 必要なら「用紙を調整」で傾きや余白を直す
3. 「文章」タブに書きたい文章を入力
4. 点線の枠を書き出し位置に合わせ、右下の丸で普段の自分の字の大きさに合わせる
5. 収まり具合を見ながら調整し、「画像を保存」

キーボードでは、枠を選んで矢印キーで移動、Shift＋矢印で枠の大きさ、＋／−で文字サイズを変えられます。

## 動かし方

`index.html` 1ファイルだけで動きます。ブラウザで開くか、GitHub Pagesなどの静的ホスティングに置いてください。フォントは Google Fonts（Klee One、Yomogi、Noto Sans JP）から読み込みます。
